# Security policy

Report vulnerabilities privately via **Security → Report a vulnerability** on the GitHub repository. Include the commit or version, macOS version, and a minimal reproduction. Do not post sensitive media, private paths, or exploit details in a public issue.

Security fixes are made on `main`; there is no maintained legacy branch. Use a current build and keep macOS updated, since audio parsing and decoding use Apple system frameworks. Ordinary bugs can be filed as public issues.
